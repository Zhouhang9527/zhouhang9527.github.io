# GINKA UI maintenance
For UI work, read `design-system/ginka/MASTER.md` and the corresponding page override before changing markup or styles. Preserve Hexo/NexT and the original GINKA art direction. Use current semantic tokens instead of introducing unrelated CSS palettes, and test both themes and mobile sizes. Do not overwrite existing design decisions with generic generator output. Consult upstream UI UX Pro Max for targeted UX outcomes; run the optional reference generation workflow for a fresh candidate, review it before adoption. All game extraction extras stay local unless distribution rights are confirmed. Maintain site/theme template parity and keep unrelated working tree changes. No automatic production deployment.
