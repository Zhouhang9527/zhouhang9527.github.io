## 🎨 ATRI Live2D 交互

ATRI 会出现在页面右下角,具有以下功能:

- **鼠标跟踪**: ATRI 的眼睛和头部会跟随鼠标移动
- **点击交互**: 点击 ATRI 会播放随机动作
- **闲置动画**: 每 15 秒自动播放一次闲置动画
- **响应式**: 自动适配桌面和移动设备

**控制台日志:**
```
[ATRI] 等待库加载...
[ATRI] ✓ 所有库加载完成!
[ATRI] 开始加载模型: /live2d/ATRI/ATRI.model3.json
[ATRI] 模型加载成功!
```

## ⚠️ 常见问题

### Q1: PowerShell 脚本无法运行
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### Q2: ATRI 不显示
1. 打开浏览器控制台(F12)
2. 查看是否有 `[ATRI]` 开头的日志
3. 确认模型文件位于 `/live2d/ATRI/`
4. 尝试强制刷新(Ctrl+F5)

### Q3: 中文显示乱码
脚本已自动处理 UTF-8 编码。如果仍有问题:
```powershell
chcp 65001
```

### Q4: 服务器端口被占用
修改端口:
```bash
hexo server -p 5000
```
