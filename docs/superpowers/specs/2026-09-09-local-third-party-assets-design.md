# 第三方静态资源本地化设计

## 目标

把影响页面首屏与交互的第三方静态依赖改为由 `www.mm9527.top` 同域提供，减少国内访问时对 jsDelivr、Google Fonts 与字体镜像的依赖。生成后的页面在第三方静态 CDN 不可用时仍可正常显示、搜索、切页和播放页面动画。

## 已选方案

采用“按需依赖锁定 + 构建时发布”的方式：依赖由 npm 精确锁定版本，Hexo 构建时只把当前页面实际使用的文件发布到站内固定路径。没有使用 NexT 的全量插件包，因为它会安装大量未启用的评论、公式和搜索组件；NexT 当前启用的依赖、自定义效果和字体统一由本地资源发布脚本处理。

没有采用以下方案：

- 继续使用第三方 CDN 并增加备用地址：部署简单，但首次加载仍受跨域连接和国内线路波动影响。
- 直接把压缩后的第三方文件手工提交到 `source/`：运行时稳定，但升级、许可证记录和版本追踪更容易失控。

## 本地化范围

- NexT 页面依赖：Anime.js、PJAX、Fancybox、Lozad、Font Awesome、Animate.css 和本地搜索脚本。
- 自定义效果依赖：GSAP、ScrollTrigger 与 Canvas Nest。
- 字体：Noto Serif SC 与 JetBrains Mono，使用本地 WOFF2；只发布页面实际引用的字重和字体文件。
- 删除已经失去作用的 jsDelivr、Google Fonts 和字体镜像预连接提示。

以下内容保持外部访问：

- `https://meting.mm9527.top/api`，它是动态音乐解析接口。
- 百度统计脚本，属于第三方动态统计服务。
- GitHub、游戏官网等用户主动点击的普通链接。
- ATRI 语音音频 CDN 兜底。语音文件体积大、不是页面关键依赖；本地配置仍优先，远端音频只在用户触发语音时请求。

## 架构与数据流

1. `package.json` 只精确锁定 NexT 当前启用的前端包，以及 GSAP、Canvas Nest 和字体包。
2. NexT 的 `vendors.plugins` 切换为 `custom`，统一生成 `/vendor/${npm_name}/${version}/${minified}` 形式的同域地址。
3. 一个职责单一的 Hexo 生成器从已安装依赖中读取主题依赖、自定义效果和字体文件，发布到对应的 `/vendor/` 路径。
4. 自定义加载器只引用站内绝对路径；字体样式也从站内加载。
5. Cloudflare 将 `.js`、`.css`、`.woff2` 等文件作为现有静态资源缓存，部署后的主站缓存清理流程会使新版本及时生效。

## 失败处理

- 如果所需 npm 文件不存在，构建立即失败并指出缺失包或文件，避免部署一个交互残缺的网站。
- GSAP 和 Canvas Nest 仍保持延迟加载；单个可选效果加载失败时不阻塞正文、导航或音乐。
- 不为本地依赖保留远程 CDN 回退，确保检测能发现遗漏，而不是在开发环境中悄悄恢复外链。

## 验证

- 增加回归检查，扫描生成首页及自定义加载器，禁止页面关键资源出现 jsDelivr、Google Fonts 或字体镜像地址。
- 验证生成目录中存在所有已引用的本地 JS、CSS、字体及 Font Awesome webfont。
- 运行现有 `npm run check`，确保性能、无内联脚本、发布资源与音乐源检查继续通过。
- 运行 `npm run build:release`，并从生成首页提取 `script` 与 `link` 地址，确认关键第三方静态请求已经归零。

## 非目标

- 不下载或镜像 Meting 返回的音乐地址。
- 不迁移百度统计、评论后端或其他动态服务。
- 不把体积庞大的 ATRI 全量语音库加入博客仓库。
- 不改变页面视觉设计、动画触发条件或功能开关。
