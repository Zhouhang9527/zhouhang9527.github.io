# 创建桌面快捷方式教程

## 方法1: 手动创建快捷方式(推荐)

### 为 deploy.bat 创建快捷方式(最简单)
1. 找到 `d:\GINKA-Blog\deploy.bat` 文件
2. 右键点击 → "发送到" → "桌面快捷方式"
3. 完成!双击桌面图标即可一键部署

### 为 PowerShell 脚本创建快捷方式
1. 在桌面右键 → "新建" → "快捷方式"
2. 输入以下命令:
   ```
   powershell.exe -ExecutionPolicy Bypass -File "d:\GINKA-Blog\deploy.ps1"
   ```
3. 点击"下一步"
4. 命名为 "Hexo 一键部署"
5. 点击"完成"

## 方法2: 使用 PowerShell 自动创建

### 创建 deploy.bat 的桌面快捷方式
```powershell
$WshShell = New-Object -ComObject WScript.Shell
$Shortcut = $WshShell.CreateShortcut("$env:USERPROFILE\Desktop\Hexo一键部署.lnk")
$Shortcut.TargetPath = "d:\GINKA-Blog\deploy.bat"
$Shortcut.WorkingDirectory = "d:\GINKA-Blog"
$Shortcut.Description = "Hexo 一键清理和本地部署"
$Shortcut.Save()
Write-Host "桌面快捷方式已创建!" -ForegroundColor Green
```

### 创建 PowerShell 脚本的桌面快捷方式
```powershell
$WshShell = New-Object -ComObject WScript.Shell
$Shortcut = $WshShell.CreateShortcut("$env:USERPROFILE\Desktop\Hexo一键部署(PS).lnk")
$Shortcut.TargetPath = "powershell.exe"
$Shortcut.Arguments = "-ExecutionPolicy Bypass -File `"d:\GINKA-Blog\deploy.ps1`""
$Shortcut.WorkingDirectory = "d:\GINKA-Blog"
$Shortcut.Description = "Hexo PowerShell 部署脚本"
$Shortcut.Save()
Write-Host "桌面快捷方式已创建!" -ForegroundColor Green
```

### 创建快速构建快捷方式
```powershell
$WshShell = New-Object -ComObject WScript.Shell
```

## 使用技巧

### 设置快捷方式图标
1. 右键点击桌面快捷方式 → "属性"
2. 点击"更改图标"
3. 选择喜欢的图标(可以使用 `%SystemRoot%\System32\shell32.dll` 中的图标)

### 设置快捷键
1. 右键点击桌面快捷方式 → "属性"
2. 在"快捷键"栏中按下想要的组合键(如 Ctrl+Alt+H)
3. 点击"确定"

### 置顶到任务栏
- 将桌面快捷方式拖拽到任务栏即可固定

## 推荐配置

建议创建两个快捷方式:

1. **Hexo 一键部署** (deploy.bat)
   - 用于日常开发和预览
   - 双击后自动清理、生成、启动服务器

2. **Hexo 快速构建** (build.ps1)  
   - 用于快速构建静态文件
   - 不启动服务器,适合准备部署

## 注意事项

- 确保路径 `d:\GINKA-Blog` 是正确的
- PowerShell 脚本需要设置执行策略(首次运行时)
- batch 脚本 (deploy.bat) 最简单,推荐新手使用

## 自动创建所有快捷方式

复制以下代码到 PowerShell 并运行:

```powershell
# 创建 deploy.bat 快捷方式
$WshShell = New-Object -ComObject WScript.Shell

# 一键部署
$Shortcut1 = $WshShell.CreateShortcut("$env:USERPROFILE\Desktop\Hexo一键部署.lnk")
$Shortcut1.TargetPath = "d:\GINKA-Blog\deploy.bat"
$Shortcut1.WorkingDirectory = "d:\GINKA-Blog"
$Shortcut1.Save()

# 快速构建
$Shortcut2 = $WshShell.CreateShortcut("$env:USERPROFILE\Desktop\Hexo快速构建.lnk")
$Shortcut2.TargetPath = "powershell.exe"
$Shortcut2.Arguments = "-ExecutionPolicy Bypass -File `"d:\GINKA-Blog\build.ps1`""
$Shortcut2.WorkingDirectory = "d:\GINKA-Blog"
$Shortcut2.Save()

Write-Host "✓ 已在桌面创建两个快捷方式!" -ForegroundColor Green
Write-Host "  - Hexo一键部署.lnk (完整部署)" -ForegroundColor Cyan
Write-Host "  - Hexo快速构建.lnk (仅构建)" -ForegroundColor Cyan
```
