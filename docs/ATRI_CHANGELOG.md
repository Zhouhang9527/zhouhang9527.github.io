## 🔄 升级指南

### 从 v1.0 升级到 v2.0

#### 1. 备份原文件
```bash
# 备份旧版本
cp themes/next/layout/_partials/atri-live2d.njk atri-live2d.njk.v1.bak
```

#### 2. 替换核心文件
- 用新版本 `atri-live2d.njk` 替换旧文件
- 添加 `source/_data/atri-config.js` 配置文件

#### 3. 更新配置
```javascript
// 旧版本配置（v1.0）
const config = {
  modelPath: '/live2d/ATRI/ATRI.model3.json',
  scale: 0.35
};

// 新版本配置（v2.0）
const CONFIG = {
  modelPath: '/live2d/ATRI/ATRI.model3.json',
  width: 350,
  height: 500,
  scale: 0.25,
  mobileScale: 0.18,
  enableDrag: true,
  enableMessage: true,
  enableControls: true
};
```

#### 4. 清理缓存
```bash
hexo clean
rm -rf .deploy_git
```

#### 5. 重新生成
```bash
hexo generate
hexo server
```

#### 6. 验证功能
- 使用 [验证清单](ATRI_VERIFICATION_CHECKLIST.md) 测试所有功能
- 检查浏览器控制台日志
- 确认没有错误
