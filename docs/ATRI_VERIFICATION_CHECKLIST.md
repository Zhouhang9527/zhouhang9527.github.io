# ✅ ATRI Live2D v2.0 功能验证清单

## 📋 使用说明

本清单用于验证 ATRI Live2D v2.0 的所有功能是否正常工作。请按照顺序逐项检查。

**验证环境**: 
- 浏览器: Chrome/Firefox/Edge (推荐 Chrome)
- 设备: 桌面端和移动端分别测试
- 网络: 本地服务器 `hexo server` 或已部署站点

---

## 🔍 预检查项

### 1. 文件完整性检查

- [ ] `themes/next/layout/_partials/atri-live2d.njk` 文件存在
- [ ] `source/_data/atri-config.js` 文件存在
- [ ] `public/live2d/ATRI/` 目录存在
- [ ] `public/live2d/ATRI/ATRI.model3.json` 文件存在
- [ ] Live2D 库文件已加载（检查 network 面板）

### 2. 配置检查

- [ ] `_config.next.yml` 中 `custom_file_path.bodyEnd` 已配置
- [ ] `body-end.njk` 文件包含 ATRI 引入代码
- [ ] 配置文件中的路径正确（相对于 public 目录）

---

## 🎯 核心功能验证

### 1. ATRI 显示 ✅

**步骤**:
1. 打开博客页面
2. 等待页面完全加载

**预期结果**:
- [ ] ATRI 出现在右下角
- [ ] ATRI 模型渲染正常（无黑屏/白屏）
- [ ] ATRI 的大小合适（不过大或过小）
- [ ] ATRI 的位置正确（在可视范围内）

**如果失败**:
- 打开控制台（F12）查看错误
- 检查是否有 `[ATRI]` 开头的错误日志
- 确认看到 `[ATRI] 初始化成功!`

---

### 2. 欢迎消息 ✅

**步骤**:
1. 首次打开页面或刷新页面
2. 观察 ATRI 上方

**预期结果**:
- [ ] 出现对话框
- [ ] 显示欢迎消息（如："你好呀！我是 ATRI~"）
- [ ] 对话框有渐变背景
- [ ] 对话框有三角形指示器
- [ ] 3秒后自动消失

**如果失败**:
- 检查配置：`enableMessage: true`
- 查看控制台是否有 JavaScript 错误
- 确认 `messages.welcome` 配置正确

---

### 3. 鼠标跟踪 ✅

**步骤**:
1. 在 ATRI 周围移动鼠标
2. 观察 ATRI 的眼睛和头部

**预期结果**:
- [ ] ATRI 的眼睛跟随鼠标移动
- [ ] ATRI 的头部略微转动
- [ ] 移动平滑，无卡顿
- [ ] 转动范围合理（不超过 ±30°）

**如果失败**:
- 检查是否为移动设备（移动端默认禁用）
- 查看控制台是否有参数更新错误
- 确认 `mousemove` 事件正常触发

---

### 4. 点击互动 ✅

**步骤**:
1. 点击 ATRI
2. 观察反应

**预期结果**:
- [ ] 显示互动消息（如："呀！不要戳我~"）
- [ ] 播放点击动画
- [ ] 控制台输出：`[ATRI] 播放动作: Tap`
- [ ] 可以多次点击，每次消息可能不同

**如果失败**:
- 检查 `click` 事件是否绑定
- 查看 `messages.click` 配置
- 确认 `pointer-events` CSS 属性正确

---

### 5. 鼠标悬停 ✅

**步骤**:
1. 将鼠标悬停在 ATRI 上（不点击）
2. 等待 1-2 秒
3. 多次重复测试（因为是 30% 概率）

**预期结果**:
- [ ] 约 30% 概率显示悬停消息
- [ ] 消息如："在看什么呢？"
- [ ] 不是每次都显示（符合概率设定）

**如果失败**:
- 检查 `mouseenter` 事件
- 多试几次（概率性触发）
- 确认 `messages.hover` 有内容

---

### 6. 复制内容 ✅

**步骤**:
1. 选中页面任意文字
2. 按 `Ctrl+C` 复制
3. 观察 ATRI

**预期结果**:
- [ ] ATRI 显示复制提示
- [ ] 消息如："复制成功啦！"
- [ ] 控制台可能有日志

**如果失败**:
- 检查 `copy` 事件监听
- 确认 `messages.copy` 配置
- 查看是否有权限问题

---

### 7. 页面滚动 ✅

**步骤**:
1. 滚动页面上下浏览
2. 多次滚动（10% 概率）
3. 观察 ATRI

**预期结果**:
- [ ] 约 10% 概率显示滚动消息
- [ ] 消息如："慢慢看哦~"
- [ ] 不会频繁打扰（低概率）

**如果失败**:
- 检查 `scroll` 事件
- 确认 `messages.scroll` 配置
- 多滚动几次测试概率
