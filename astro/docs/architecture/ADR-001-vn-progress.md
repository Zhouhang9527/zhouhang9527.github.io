# ADR-001 — VN stage and progress-dependent title background
Status: implemented first slice, pending browser acceptance.
Single content route architecture: title and archive are game surfaces; articles stay native reader surfaces. No separate router. Original GINKA changes the title backdrop with story progress (reference: https://kannagi35.com/content/ginka-walkthrough). For the blog, explicit completed articles control four provisional cover states (0 / 1 / 3 / 8 distinct current articles). Revisiting does not advance progress. Progress remains local; users can undo the mark. Continue uses the last valid known article, not a fake save slot. This first slice restores only the route, not heading-relative position yet. Exact original title art/sequence is unverified; existing tracked art is preview-only, not a grant of publication rights. Day/moonlit remains independent of progress. No new extraction or deployment.
