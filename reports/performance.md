# 性能与质量升级记录

日期：2026-10-16（Asia/Shanghai）。原始记录保存在 [优化前](performance-before.json) 和 [优化后](performance-after.json)。

## 冷启动资源

| 视口 | 优化前 | 优化后 | 资源体积减少 | 请求数 |
| --- | ---: | ---: | ---: | ---: |
| 390px | 1.225 MB | 0.577 MB | 52.9% | 46 → 41 |
| 1440px | 4.124 MB | 0.763 MB | 81.5% | 59 → 42 |

统计范围是首页加载完成后的 3.5 秒内、同源 Resource Timing 条目的 encodedBodySize；不含导航 HTML 和跨域统计脚本。每次使用新的浏览器上下文并阻止 Service Worker，使用本地未压缩 HTTP 预览。结果用于比较资源量，线上压缩传输、设备和网络条件会影响实际耗时。

桌面脚本资源从 1,423,185 字节降至 154,106 字节。主要收益来自延后加载 Live2D、模型、语音和动画，以及点击图片后再加载灯箱。

## 具体变更

- 首次互动后在空闲时加载桌面角色和 GSAP；低功耗或减少动态效果模式保留轻量体验。
- 侧栏打开时加载音乐，失败后可重试；灯箱首次点击时加载，失败时仍可查看原图。
- 统一脚本与样式加载器，对并发请求去重，支持失败清理和超时重试；隐藏标签页暂缓后台任务。
- Font Awesome 只打包本站使用的字形，保留原许可和可重复构建脚本；移除未使用的 Noto Serif 字体与 Lozad。
- 图标字体约 237 KB 降为约 10 KB，图标 CSS 约 74 KB 降为约 12 KB。
- 缓存按内容哈希和固定库版本复用；已缓存文章在慢连接与服务器错误时仍可阅读，运行缓存限定容量并隔离其他应用缓存。
- 性能监测使用 [Google web-vitals](https://github.com/GoogleChrome/web-vitals) 6.2.3，记录 LCP、INP、CLS、FCP 和 TTFB。指标仅在本地保存，PJAX 切换耗时单独记录。
- 修正 JPEG 头像与图标的文件类型及安装元数据，补充轻量 404 页面，保留代码和链接的原生右键菜单。

- 30 项浏览器检查：四种视口、搜索与索引失败重试、代码复制和滚动、阅读位置、标签筛选、灯箱、音乐重试、桌面互动、离线与无 JavaScript 阅读。
