# 全面优化发布记录 · 2026-10-16

## 内容和维护

- 65 个页面、15 篇文章由同一公共布局和侧栏模板生成。
- 正文片段保留原有代码；发布地址保持不变。每篇文章输出三篇独立相关推荐。
- 原图作为回退，10 张插图提供 WebP 尺寸变体。首页主图的预加载与 `srcset` 一致。
- 长代码可展开或换行，复制始终使用完整源码；系统减少动态效果偏好受到尊重。
- 文章目录跟随当前章节；搜索按标题和标签加权，安全显示匹配片段、日期和标签。
- 构建自动同步资源内容哈希、搜索索引、文章目录和可核验的内容版本。

## 发布路径

沿用 GitHub Pages 的 `main` 分支根目录和 `www.mm9527.top` 域名。
发布后以 Pages 构建提交和线上 `site-version.json` 核对版本，再检查真实浏览器中的首页、文章和搜索。

线上兼容性：全部可执行脚本保持原生 defer 顺序，搜索可在文档就绪后初始化，避免 CDN 延迟脚本处理导致交互缺失。

核心启动改为检查实际 DOM，主题启动保持幂等；侧栏由公共控制器管理，离线注册在空闲时执行。测试额外模拟文档就绪状态与加载事件被 CDN 代理的情况。

文章卡片移除旧主题遗留的顶部空隙，宽屏目录避开导航区域；发布完成后按页面 URL 精确刷新 CDN 缓存。

## 2026-10-16 Live2D 修复

ATRI 的动态脚本使用内容版本，模型、纹理及首帧绘制完成后才进入就绪状态，再启用欢迎提示和附属功能。
加载失败提供重试，重试会清理旧实例与按钮监听。功能面板通过明确按钮展开，位于模型下方，支持键盘关闭。
小窗口可手动开启；清除了旧的固定画布尺寸及缩放规则，模型与面板适配手机、平板和横屏。

33 项基础检查、60 个脚本语法检查、65 页构建一致性和 46 项浏览器检查通过。
新增验证覆盖真实模型像素、慢速纹理的就绪顺序、模型失败重试、语音入口、动作、音量、截图下载、拖动复位和收起唤回。
手动开启验证包括 320 / 390 / 768 / 1024 像素与短横屏。完整记录见 `live2d-quality.json`。

后续按用户要求移除「ATRI · 功能」开关：页面就绪后自动加载模型，附属按钮随完整模型一起显示。
手机、桌面和减少动态效果模式均不再要求首次点击；手动收起后保留唤回入口。
性能预算现在计入自动加载的 Live2D 运行库与模型，音乐、画廊和滚动特效继续按需加载。
云端浏览器会提前加载更多临近视口的原生延迟图片，桌面预算覆盖这部分差异；功能检查不依赖外部统计服务可用性。
