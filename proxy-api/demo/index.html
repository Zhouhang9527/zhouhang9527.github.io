🔁 反向代理 API 功能演示

确保已在本地执行 npm start，服务器默认运行在 http://localhost:3000（端口可通过 PORT 环境变量修改）

① 跨域请求解决（CORS）

GET

前端直接请求 api.github.com 会被浏览器拦截（跨域）。 通过本代理服务器中转，统一添加 CORS 响应头，前端即可无障碍访问。

// 点击「发送」查看结果

② 响应缓存（Cache）

GET

连续发送相同请求，首次为 MISS（实际请求目标服务器）， 之后 30 秒内返回 HIT（直接读缓存），速度更快、消耗更少。 观察响应头 X-Cache 的变化。

// 连续点击两次，对比 X-Cache 头

③ 请求 & 响应体改写（Transform）

POST

代理层在转发前自动向请求体追加 _proxy: true 和 _timestamp 字段， 收到响应后再追加 _note 字段。演示如何在不修改客户端的前提下改写数据。

// 点击「发送」查看改写后的请求体

④ 请求限速（Rate Limiting）

GET

OpenAI / GitHub 等路由设有每分钟请求上限。 连续快速点击多次后会收到 429 Too Many Requests， 同时响应头 X-RateLimit-Remaining 会实时递减。

// 点击「连发 35 次」后查看 429 响应

⑤ Authorization 头透传

GET

在输入框中填入任意 Token，代理会将其原样注入到转发请求的 Authorization 头中。 httpbin 会将收到的所有请求头原样返回，方便验证头是否到达目标服务器。

// 填入 Token 后点击发送

⑥ 健康检查 & 路由列表

GET

代理服务器自身提供 /health（健康检查）和 /（查看所有代理规则）两个管理端点， 方便监控服务是否正常运行。
